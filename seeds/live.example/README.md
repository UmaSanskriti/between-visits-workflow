# Live demo seeds

Copy this folder to `seeds/live/` (gitignored) and replace the number with a team-owned phone you have
explicit consent to call. The same number must be in `.env` as `BV_LIVE_ALLOWLIST`, or the gate blocks it.

For the email demo put your own address in `demo.csv` (email column) and `clearances.csv`, and add it to
`BV_LIVE_ALLOWLIST` in `.env` (comma-separated with the phone number).
